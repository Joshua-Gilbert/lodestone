# rom

Our notes on the GRiDCase 1520's firmware. The images themselves are not in this repo.

- `GRID1520_BIOS_891025.map` is a symbol map of the 1520 BIOS (dated 89-10-25) that we built while reading it.
- `GPROBE_2026-10-04.TXT` is the output of GRIDPROBE.COM on the 1520.

Put the GRiD MS-DOS 3.30 EPROM image here as `GRID_MSDOS330_ROM_300909-00.BIN` (it's ignored by git), or point `GRID_ROM` at it. The bench comparison and the "GRiD MS-DOS: map only" DEFRAG check need it.
