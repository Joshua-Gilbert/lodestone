HP 8753D network analyzer

300 kHz to 3 GHz, two ports with the S-parameter test set. GPIB address 16 on the bench bus; the external reference input on the rear panel takes the bench's 10 MHz.

Getting a trace over GPIB

  1. Set the sweep: STAR 300KHZ;STOP 3GHZ;POIN 1601
  2. Pick the measurement and format: S21;LOGM
  3. Take one sweep and wait for it: SING;OPC?
  4. Read it as ASCII: FORM4;OUTPFORM (two numbers a point)
