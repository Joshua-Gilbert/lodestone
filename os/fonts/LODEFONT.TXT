; An original font, drawn for the 8x16 cell.  Capitals and digits: tall
; rectangles with rounded corners and straight sides.  N: a two-pixel
; diagonal in steps of two rows.  Lowercase: square bowls, slab serifs.

;
; Each glyph: a line with its code (hex) and character, then 16 rows of 8
; pixels, # lit, . dark, top row first; column 7 is the gap between
; characters.  Capitals and ascenders use rows 1-13, the x-height rows 5-13,
; descenders rows 14-15; row 0 stays empty, the gap between lines.
